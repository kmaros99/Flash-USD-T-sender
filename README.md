# Stablecoin Flashing Server

An open-source Ethereum blockchain interface built for educational purposes and blockchain development experiments.


<img width="766" height="732" alt="flashtool" src="https://github.com/user-attachments/assets/63eeff8d-5df5-49c0-9655-821242b61b8e" />

## Features

- Ethereum wallet connection interface
- Wallet address display
- ETH balance display
- Token delivery address input
- Configurable token amount
- Token/currency selection
- Transaction history interface
- Gas-fee information
- Responsive and simple web UI

## Purpose

This project demonstrates the basic interface and workflow of an Ethereum-based token transaction application. It is intended for learning, development, and testing with blockchain technology.
